# VOLT Automation Scripts

This directory houses command-line automation and simulation scripts:

- `generate_synthetic_data.py`: (Scheduled for Phase 2) Generates reproducible five-year hourly demand, solar, wind, and IEX price series tagged `SYNTHETIC`.
- `run_backtest.py`: (Scheduled for Phase 3) Chronological rolling-origin evaluation of forecasting models against seasonal-naive baselines.
- `run_scenario.py`: (Scheduled for Phase 4 & 5) Batch evaluation of disturbance scenarios across operating policies.
